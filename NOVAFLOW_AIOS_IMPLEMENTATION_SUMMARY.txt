--------------------------------------------------------------------------------
2. KEY CHAT & BACKEND ARCHITECTURAL SHIFTS
--------------------------------------------------------------------------------
* Goal-Driven Composition: The chat interface is the control center. The user 
  never manually configures database models, workflows, nodes, or connectors. 
  They submit a goal (e.g., "I want a restaurant ordering system via telegram"), 
  and the AI Kernel designs a "Solution Graph".
* Solution Graphs over Workflows: Workflow compilation is only one possible 
  execution artifact. Solution Graphs contain agents, memory tables, knowledge 
  indices, background workers, webhook listeners, and third-party APIs.
* Just-In-Time Credentials: Never ask for connection tokens up front. The 
  Composer Planner builds the graph first, and prompts the user inside the chat 
  view for secrets (e.g., Telegram Bot Token) only when they are needed.
