1. HOW THE TELEGRAM BOT WORKS IN NOVAFLOW AI
--------------------------------------------------------------------------------
- NovaFlow AI integrates with Telegram using official Telegram Webhooks.
- When any public user on any phone sends a message to your Telegram bot (e.g., @Novaflow_text_bot), Telegram receives the message and forwards a JSON payload to NovaFlow AI's webhook endpoint:
  https://<your-domain-or-ngrok>/api/v1/integrations/telegram/webhook/<workflow_id>

- The webhook handler (telegram_webhook in backend/app/routers/integrations.py):
  1. Parses incoming JSON payload from Telegram using parse_telegram_input().
  2. Extracts the user's Chat ID (chat_id), message text, first name, and username.
  3. Evaluates custom bot command triggers (such as /greetings or /start).
  4. Passes the message and metadata into NovaFlow's workflow engine (run_workflow) with context variables:
     - {{chat_id}} -> Recipient Chat ID for sending replies.
     - {{user_name}} -> Sender's display name or username.
     - {{first_name}} -> Sender's first name.
  5. The LLM processes the user prompt and generates an AI response.
  6. The Notify / Telegram node sends the response directly back to the sender's Telegram chat.


2. HOW THE /greetings COMMAND CONDITION IS IMPLEMENTED
--------------------------------------------------------------------------------
- In backend/app/services/integrations.py:
  parse_telegram_input() extracts the sender's name from the Telegram update payload:
    message = payload.get("message") or payload.get("edited_message")
    sender = message.get("from") or message.get("chat")
    first_name = sender.get("first_name")
    username = sender.get("username")
    user_name = first_name or username or "User"

- In backend/app/routers/integrations.py:
  When a message starts with "/greetings" or "/start":
    if text.lower().startswith("/greetings") or text.lower().startswith("/start"):
        greeting_text = f"Hello {user_name}! 👋 Welcome to NovaFlow AI. How can I assist you today?"
        await send_telegram_message(db, wf.workspace_id, chat_id, greeting_text)


3. HOW TO CHANGE OR CUSTOMIZE THE GREETING RESPONSE
--------------------------------------------------------------------------------
Option A: Modify the Default Python Webhook Code
  - Open: backend/app/routers/integrations.py
  - Locate: telegram_webhook()
  - Change the greeting_text template string to your desired text, e.g.:
    greeting_text = f"Welcome {user_name}! 🚀 I am your custom NovaFlow assistant."

Option B: Customize Greetings inside the Workflow Visual Canvas
  - In NovaFlow Canvas, you can use the variable {{user_name}} in your LLM node prompt or Notify node template!
  - Example LLM System Prompt:
    "If the input is /greetings, greet {{user_name}} by name warmly and introduce your features."
